## [0.1.0] - 2026-11-01

### Added

- Initial bundle release for DeepSeek Harness `0.2.1-rc.5`.
- Turn-end token measurement with `total` (cumulative billed tokens) and
  `context` (request pressure) metrics, threshold defaulting to 100,000,000.
- Per-session trigger ledger with re-arm-after-success and bounded failure retry.
- Handoff brief generated by one auxiliary `ctx.llm.stream()` call that never
  touches the summarized session.
- Guaranteed inclusion of the session's original first user prompt, read from
  the `titleInput` projection and appended to the handoff task when a custom
  template omits it.
- Fresh agent created through `ctx.subagents.startActivation` with the `spawn`
  provider; delivery policy configurable as `parent` or `caller`.
- Subagent-session recursion guard and failed-turn filtering.
- `dryRun` mode and a strict schemastery `Config` schema.
- Unit tests over a fake Cordis context and a GitHub Actions verify pipeline.
